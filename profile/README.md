# Avibe

### The local-first Agent OS — your AI partner lives on your own machine.

**Own the agent. Reach it from anywhere. Never get locked in.**

[Website](https://avibe.bot) · [Docs](https://docs.avibe.bot) · [Start here → avibe](https://github.com/avibe-bot/avibe) · [中文 ↓](#中文)

</div>

One command turns your machine into a home for your AI partner. Message it, and the work gets done.

Avibe drives the **official** Claude Code, Codex, and OpenCode — from your browser, or from any chat app you already use (Slack, Discord, Telegram, WeChat, Lark/Feishu) — while your code and keys stay on your own machine. `avibe.bot` only brokers identity and the tunnel, never your data.

```bash
curl -fsSL https://avibe.bot/install.sh | bash && vibe
```

## What lives here

| Repo | What it is |
| --- | --- |
| **[avibe](https://github.com/avibe-bot/avibe)** | The Agent OS itself: Workbench, Agent Harness, Skills, Show Pages, and all the chat-platform connectors. Start here. |
| **[askill](https://github.com/avibe-bot/askill)** | Package manager for AI agent skills. Install a skill once; every agent you run inherits it. |
| **[avault](https://github.com/avibe-bot/avault)** | Rust key-custody core behind Avibe Vaults, the only component that holds keys or does crypto. |
| **[vault-sandbox](https://github.com/avibe-bot/vault-sandbox)** | The crypto sandbox served at `sandbox.avibe.bot`. Public and auditable by design. |
| **[vibe-show-runtime](https://github.com/avibe-bot/vibe-show-runtime)** | Runtime packages that power interactive Show Pages. |

> 💚 **Built with Avibe.** This project was developed end-to-end using Avibe itself — steering Claude Code, Codex, and OpenCode from the browser and from my phone. — [@alex_metacraft](https://x.com/alex_metacraft)

### Avibe 是本地优先的 Agent OS——你的 AI 伙伴，住在你自己的机器上。

**拥有你的 agent。随处都能找到它。永不被锁死。**

[官网](https://avibe.bot) · [中文文档](https://docs.avibe.bot/zh) · [从这里开始 → avibe](https://github.com/avibe-bot/avibe/blob/master/README_ZH.md) · [English ↑](#avibe)

</div>

一条命令，把你自己的机器变成 AI 伙伴的家，发条消息，它就替你把活干了。

Avibe 驱动的是**官方**的 Claude Code、Codex、OpenCode。你在浏览器里，或在你已经在用的聊天软件里（Slack、Discord、Telegram、微信、飞书）和它协作，而代码与密钥都留在你自己的机器上，`avibe.bot` 只负责身份和隧道，不经手你的数据。

```bash
curl -fsSL https://avibe.bot/install.sh | bash && vibe
```

## 这里有什么

| 仓库 | 是什么 |
| --- | --- |
| **[avibe](https://github.com/avibe-bot/avibe/blob/master/README_ZH.md)** | Agent OS 本体：Workbench、Agent Harness、Skills、Show Pages，以及所有聊天平台接入。从这里开始。 |
| **[askill](https://github.com/avibe-bot/askill)** | AI agent 技能的包管理器。技能装一次，你跑的每个 agent 都继承。 |

| **[vault-sandbox](https://github.com/avibe-bot/vault-sandbox)** | 部署在 `sandbox.avibe.bot` 的加密沙箱，公开、可审计。 |
| **[vibe-show-runtime](https://github.com/avibe-bot/vibe-show-runtime)** | 驱动交互式 Show Pages 的运行时包。 |
